DESI UTILITY — STARTER WEBSITE
================================

Included:
- Responsive homepage with tool search
- English, Hindi and Bengali homepage interface translations
- Percentage calculator
- Age calculator
- Date difference calculator
- Word counter
- Case converter
- Text cleaner
- About, Contact, Privacy Policy and Terms pages
- Basic robots.txt and sitemap.xml placeholders

HOW TO TEST
1. Extract this ZIP.
2. Open index.html in a modern browser.
3. Open each tool from the homepage and test it.
4. For best local testing, run a simple local static server (optional).

HOW TO PUBLISH FREE
1. Create a GitHub account and a new repository.
2. Upload the extracted files while preserving the folder structure.
3. In Cloudflare Pages, create a project connected to the repository.
4. Use the framework preset "None" and leave build command blank; set output directory to / (or the repository root as guided by the current dashboard).
5. Deploy and test every page on the generated URL.
6. Replace YOUR-DOMAIN.example in robots.txt and sitemap.xml with your real deployed URL.
7. Add the site to Google Search Console and submit sitemap.xml.

IMPORTANT
- This is a static starter, not yet a published website. It does not include a live domain or hosting account.
- The contact page is a placeholder; add a real contact method before public launch.
- Review the privacy policy after adding ads, analytics, cookies, or third-party services.
- AdSense approval and earnings are not guaranteed. Apply only after the site has useful original content and complies with current policies.
- The homepage has English/Hindi/Bengali UI translations. Tool pages are currently English and can be localized in a later version.
- Test date and text tools with your expected use cases before relying on results.
